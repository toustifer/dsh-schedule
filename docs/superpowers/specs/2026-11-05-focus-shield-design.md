- **作者 / 架构**：DSH 团队 / toustifer
- **日期**：2026-11-05
- **版本**：v1.0
- **适用插件**：`dsh-schedule` (v0.5.0)

## 1. 目标与问题陈述 (Goals & Problem Statement)

### 1.1 现状与痛点
目前的 `dsh-schedule` 虽然具备五视图与全屏倒计时功能，但本质上仍属于传统的“日程列表驱动”。对于具有 ADHD 神经特质或高认知负荷的开发者/学生，存在两大核心痛点：
1. **启动瘫痪 (Task Freeze / Executive Dysfunction)**：面对堆积的长列表和 45~60 分钟的任务感到过载，导致迟迟无法从床上或闲暇中起身；
2. **时间盲与羞耻螺旋 (Time Blindness & Shame Spiral)**：死板的时钟安排易崩溃，中途暂停或失败容易诱发强烈的自我内疚，进而放弃使用工具。

### 1.2 解决方案：Focus Shield (专注盾牌) + 陪伴打怪系统
借鉴认知神经科学中的“每日唯一高光 (Daily Highlight)”、“执行意图 (Implementation Intentions)”以及“虚拟伴工替身 (Digital Body Doubling)”理论，重构「今天」视图：
1. **今日唯一主角 (Main Focus)**：顶部醒目卡片，每天只推 1 件核心任务，消除视觉噪音；
2. **双启动点火机制**：提供 `▶ 开始专注 (默认时长)` 与 `🌱 先做5分钟 (微破冰)`，将启动摩擦阻力降到趋近于零；
3. **副任务与备忘抽屉**：下方折叠收纳其余任务，支持一键 `⭐ 设为主任务`，并常驻零压力速记框；
4. **伴工角色系统**：
   - 默认形象采用深海女仆鲸鱼娘（高精卡通材质模型）；
   - 默认名称为 **「大肥鱼」**；
   - **支持用户自定义伴工名称**（如改成“小点”、“阿鲸”、“胖头鱼”等），并在对话气泡、徽章与战报中全链路动态响应；
5. **零羞耻哲学 (Zero Shame)**：退出即暂停、进度永久封存、取消过期红字，只记录完成的成就感。

### 2.2 伴工命名与交互规则

1. **命名存储**：
   - 存储键：`dsh-schedule:companion:name`（写入 `localStorage`，并在数据文件扩展字段 `ui.companionName` 中备份）；
   - 默认值：`"大肥鱼"`；
   - 修改入口：点击伴工卡片上的名字徽章，弹出原地重命名输入框，回车即保存。
2. **伴工状态与动态台词联动**：
   - **常态待命**：*“我在呢，今天想先攻哪一小步？{name}陪你。”*
   - **5分钟微破冰**：*“就先看 5 分钟！{name}在这陪着你，看不下去随时关掉～”*
   - **深度心流 (40m)**：*“进入深度心流啦，外面吵吵闹闹的都交给{name}挡着！”*
   - **暂停打盹**：*“进度帮你封存好啦，放心去喝口水/伸个懒腰，醒了继续～”*
   - **击倒完成**：*“哇！真的太厉害了！{name}为你疯狂鼓掌～又跨出了一大步！”*
3. **点击抚摸互动**：
   - 点击伴工视窗触发轻微弹跳反馈，随机刷新一段鼓励短语。

## 3. 数据契约与存储扩展 (Data Contract & Storage)

所有改动保持向前兼容，不需要变动数据文件格式主版本号 (`version: 2`)：

### 3.1 扩展字段 (`doc.ui` / `localStorage`)
```jsonc
{
  "ui": {
    "highlightId": "dt_mw0g8l77_0bz1ul", // 当前置顶为主任务的日程 ID
    "companionName": "大肥鱼",           // 用户自定义的伴工昵称，缺省为"大肥鱼"
    "drawerCollapsed": false             // 副任务抽屉的展开/折叠状态
  }
}
```

### 3.2 倒计时存储 (`cdPrefix`)
- 复用现有机制：`dsh-schedule:cd:v1:<itemId>|<date>`
- 新增支持微破冰参数：`isMicro: true, totalMs: 300000` (5分钟)

## 4. 详细组件与逻辑划分 (Component Architecture)

1. **`FocusShieldHero` (今日主角卡片)**
   - 职责：展示置顶任务、伴工视频/立绘、动态对话气泡、双启动按钮；
   - 依赖：`cdState`, `api('set-done')`, `onSwapHero`。
2. **`CompanionBox` (伴工视窗)**
   - 职责：播放轻量伴工循环动画、承载自定义改名弹窗、点击抚摸动效；
   - 尺寸：96×128px 移动端视角卡片，圆角 14px，自适应高分屏。
3. **`TaskBacklogDrawer` (副任务与灵感仓)**
   - 职责：折叠呈现非主角任务、一键 `⭐ 设为主任务`、轻量无压力速记输入框。
4. **`ZeroShameWins` (今日战报)**
   - 职责：只展示正向已完成记录，无超时惩罚。

## 5. 测试与验收标准 (Testing & Acceptance Criteria)

1. **视觉与交互测试**：
   - 默认状态下主角卡片清晰居中，伴工徽章显示为「大肥鱼 · 伴工」；
   - 点击伴工名字可自定义改名为任意文本（如“小点”），对话气泡中的称谓实时同步变更；
   - 刷新页面后，自定义名字依然保留。
2. **点火与倒计时测试**：
   - 点击「🌱 先做5分钟」，倒计时以 `05:00` 启动，提示语切换为微破冰激励文案；
   - 点击「▶ 开始专注」，倒计时按任务本身时段（或默认25/40分钟）启动；
   - 点击「⏸ 暂停」或「✕ 退出」，状态转为 `paused`，剩余秒数不丢失。
3. **主副任务切换测试**：
   - 在副任务列表中点击任意任务的「⭐ 设为主任务」，主角卡片立即平滑切换为该任务，原主角降为副任务。
4. **向后兼容性**：
   - 既有 140/140 单测全绿通过，不破坏旧版数据读写契约。
